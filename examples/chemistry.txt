====== Chemistry calculator ======

===== Interactive formula and proportion =====

<calcchem>

===== Water =====

<calcchem H2O>

===== Sodium chloride =====

<calcchem NaCl>

===== Glucose =====

<calcchem C6H12O6>

===== Grouped formula =====

<calcchem Ca(OH)2>

===== Hydrate =====

<calcchem CuSO4·5H2O>

===== Optional: formula from Struct page data =====

Requires the Struct plugin and a single text field material.formula assigned to the current page.

<calcchem {{$material.formula}}>

The equivalent reference with spaces uses Struct's own parser:

<calcchem {{$ material.formula }}>
